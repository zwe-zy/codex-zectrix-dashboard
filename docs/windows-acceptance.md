## 任务状态适用边界

只观察当前本机 API 枚举的受支持顶层任务。rc.2 额外读取当前 Codex 本地执行数据库的状态和时间列，不查询正文、回复或工具参数；数据库连接只读。运行中需 3 分钟内活动证据，结束状态需真实时间且在 24 小时内。旧数据、未来时间、未知格式或无权读取会降级，避免错误报成运行或完成。当前适配已在上述 Codex 版本验证；长时间没有新活动记录及后续存储格式变化仍可能显示未知。
