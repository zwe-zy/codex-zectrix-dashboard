Codex NOTE4 控制台 — Windows x64 0.3.0-rc.5

第一次使用（不需要 Rust / Python / Node.js）
1. 安装并打开 Windows 版 Codex，登录自己的 ChatGPT 账号。
2. 登录 https://cloud.zectrix.com，在“开放 API”创建 ZECTRIX Key。
   NOTE4 需已绑定到同一账号，并且在线。
3. 完整解压 ZIP，保留七个文件。不要在 ZIP 内直接运行。
4. 双击“NOTE4控制台.exe”，点击“安装并开始”。
5. 在“设备配置”页检查 Codex 登录，粘贴 Key，获取设备列表。
6. 选择设备和墨卡页，生成测试预览，确认后保存并上传。
7. 配置完成后，后台会更新真实数据，可以关闭控制台。

以后从开始菜单搜索“Codex NOTE4”打开。
运行总览：查看额度、任务状态、后台运行情况与最近成功上传画面。
墨卡与主题：单张直接配置，多张拖动排序；支持 2–5 张自动更新。
设备配置：首次连接或更换 Key、设备；已有 Key 可以直接复用。
设置与诊断：开关登录启动、升级、查看诊断、卸载。

单张：选择“1 张”，选择设备墨卡编号和风格，点击“保存并应用”。
多张：直接选择“2 张 / 3 张 / 4 张 / 5 张”，每张可独立选择风格。
抓住左侧“拖动”调整顺序；也可以用“上移 / 下移”。从上到下对应设备墨卡 1–N。
点击“保存并应用”后才生效，会替换所列页面；其余页面保留原图并停止更新。
“撤销未保存修改”恢复已保存的排列。状态刷新不会冲掉正在编辑的排列。
五种风格都保留单额度和双额度布局，按账号实际返回的窗口自动显示。
风格示例中的 72% / 40% 是演示数据，切换预览不会上传。
“查看设备最近上传的真实画面”显示已成功上传的图片。

额度每 10 分钟读取一次，任务每分钟读取一次；每张上传至少间隔 60 秒。
只有内容变化才更新。云端收到图片后，NOTE4 按自身同步周期刷新。
“最近成功上传”不能证明实体屏幕已刷新。后台停止时显示最后已知数据。
关闭控制台不会停止后台；需要停止时，请在总览点击“停止后台”。

升级：下载新版完整 ZIP，解压到新空目录，打开新版控制台并点击安装/升级。
保留原 Key、设备、主题和墨卡排列。若安装失败，程序尝试恢复旧版本。
旧版单页 / 固定五页设置自动兼容；保存自定义排列后，请使用 rc.4 或更新版本。
新装不需要管理员权限；迁移旧计划任务时可能请求一次 Windows 授权。

卸载：设置与诊断 → 卸载程序。默认保留配置和 Key，可分别勾选删除。
中断后可点击“继续卸载”；若程序文件已被部分清理，从完整 ZIP 打开控制台重试。
用户自己修改过的同名开始菜单快捷方式会保留。

程序目录：%LOCALAPPDATA%\CodexZectrixDashboard\app\版本
数据目录：%LOCALAPPDATA%\CodexZectrixDashboard
Key 只保存在当前用户 Windows 凭据管理器，不写入日志和配置。
安装后原解压目录可以移走，原 CLI 保留用于排错。

常见问题
找不到 Codex：安装并打开 Windows 版 Codex 后重试。
Key 被拒绝：在极趣云检查/重新创建 Key，再到设备配置页重新配置。
无设备：检查是否绑定到同一个极趣云账号。
状态暂不可用：当前 Codex 可能无法提供该状态；额度仍可独立更新。
数据旧了：查看后台是否运行，以及额度/任务各自的读取时间。
配置或启动未完成：查看中文提示；配置完成但启动失败时可单独重试启动。
停止后屏幕不清空：电子纸会保留最后画面，属于正常现象。
